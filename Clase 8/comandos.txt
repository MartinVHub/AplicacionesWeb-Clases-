-cuenta git
git config user.name MartinVHub
git config user.email villagram31@gmail.com

Comandos primera vez (en su casa):

-Instalar NodeJS

-Verificar Instalacion NodeJS:
node -v en cmd

-Verificar Instalacion npm:
npm -v

-Instalar manejador de paquetes pnpm:
https://pnpm.io/es/
https://www.npmjs.com/
npm i -g pnpm

-Verificar Instalacion pnpm:
pnpm -v


Por proyecto:

-Verificar si no existe el package .json, si no existe ejecutamos:
pn init

-Instalar paquete Five Server
pn add five-server

-Reinstalar paquetes si existe package .json
pn install

-Configurar scripts
"dev": "five-server"
